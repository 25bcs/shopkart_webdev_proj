# ShopKart
A simple React, Express and MongoDB shopping app for Labs 01 to 06.
Includes login, products, wishlist, cart, Razorpay test payments and orders.
Locally: run `npm install`, configure `backend/.env`, then run `npm run db`, `npm run seed` and `npm run dev`.
[Vercel preview](https://shopkart-webdev-proj.vercel.app) hosts only the frontend; MongoDB stays local, so login, shopping and payments work only locally.
